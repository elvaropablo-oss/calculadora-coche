Privacidad

Política de privacidad

Esta página explica de forma general qué información puede tratarse al usar CosteCoche.

Datos de las calculadoras

Los números que introduces en las calculadoras se procesan localmente en tu navegador. CosteCoche no necesita una cuenta de usuario ni un formulario de registro para realizar los cálculos.

Alojamiento

El sitio está publicado mediante GitHub Pages. Como proveedor de infraestructura, GitHub puede tratar datos técnicos necesarios para servir la web de acuerdo con sus propias políticas.

Google Analytics

CosteCoche utiliza Google Analytics únicamente cuando aceptas expresamente la categoría de analítica en el panel de privacidad. Si la rechazas, CosteCoche no activa el cargador de Google Analytics para esa visita.

Analytics puede procesar información técnica y de uso para generar estadísticas agregadas sobre visitas y navegación. Si aceptas, también registramos eventos técnicos como el uso de una calculadora, el uso de una referencia de precio de España o un clic de navegación interna. Los eventos personalizados de CosteCoche no incluyen los números que introduces en los campos. La gestión y conservación de los datos de Analytics depende de la configuración de la propiedad y de las políticas de Google.

Preferencia de privacidad

Guardamos en el almacenamiento local del navegador tu elección de privacidad, incluida la categoría de analítica, para no preguntártelo en cada página. También podemos guardar la comunidad autónoma o provincia que eliges manualmente como referencia de combustible. CosteCoche no usa GPS para obtener esa zona. Puedes cambiar las preferencias de privacidad en cualquier momento desde el pie de página y volver a España desde la página de precios.

Ubicación para buscar gasolineras

La herramienta “Gasolineras cerca de mí” solicita la ubicación únicamente después de que pulses el botón de búsqueda y aceptes el permiso del navegador. CosteCoche usa esas coordenadas en tu dispositivo para calcular distancias y no las incluye en sus eventos personalizados de Google Analytics ni las guarda como preferencia.

Cuando se muestra el mapa interactivo se cargan la biblioteca Leaflet y teselas cartográficas de OpenStreetMap. Esos proveedores externos pueden recibir datos técnicos necesarios para servir sus recursos, como la dirección IP y las peticiones de mapa.

Enlaces externos

Los enlaces a servicios externos están sujetos a las políticas de privacidad de sus respectivos responsables.

Esta política describe la configuración técnica actual del sitio. Si se incorporan formularios, publicidad, cuentas de usuario u otros proveedores, deberá actualizarse antes de utilizarlos.
