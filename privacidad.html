Privacidad

Política de privacidad

Esta página explica de forma general qué información puede tratarse al usar CosteCoche.

Datos de las calculadoras

Los números que introduces en las calculadoras se procesan localmente en tu navegador. CosteCoche no necesita una cuenta de usuario ni un formulario de registro para realizar los cálculos.

Alojamiento

El sitio está publicado mediante GitHub Pages. Como proveedor de infraestructura, GitHub puede tratar datos técnicos necesarios para servir la web de acuerdo con sus propias políticas.

Google Analytics

CosteCoche utiliza Google Analytics únicamente cuando aceptas expresamente la medición de audiencia mediante el aviso de privacidad. Si rechazas esa opción, el script de Google Analytics no se carga desde este sitio.

Analytics puede procesar información técnica y de uso para generar estadísticas agregadas sobre visitas y navegación. La gestión y conservación de esos datos depende de la configuración de la propiedad de Google Analytics y de las políticas de Google.

Preferencia de privacidad

Guardamos en el almacenamiento local del navegador tu decisión de aceptar o rechazar Analytics para no preguntártelo en cada página. Puedes cambiarla en cualquier momento desde “Preferencias de privacidad” en el pie de página.

Enlaces externos

Los enlaces a servicios externos están sujetos a las políticas de privacidad de sus respectivos responsables.

Esta política describe la configuración técnica actual del sitio. Si se incorporan formularios, publicidad, cuentas de usuario u otros proveedores, deberá actualizarse antes de utilizarlos.
